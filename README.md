# Kantan LogoMaker

A small, fast Windows tool for making logos and app/game icons. Combine **vector shapes**, **styled text** and
**imported images** on one artboard, then export crisp PNG and ICO files at several sizes in one step.

- Parametric shapes (rectangle, polygon, star, ring, gear, shield, badge, ribbon, bubble, arrow, heart, burst),
  SVG symbols and your own saved presets; pen tool and node editing for custom paths.
- Live booleans (union, subtract, intersect, exclude), offset path, outline stroke, simplify, radial repeat,
  clip groups, align/distribute, snapping and guides.
- Text from system or imported fonts (embedded in the project), tracking, line height, alignment and arc bend.
- Fill (solid, linear, radial), up to three stacked outlines, drop/inner shadow, outer/inner glow and
  bevel & emboss, with one-click style presets.
- Images with crop, adjustments, background-colour removal and clip-to-shape.
- A live size strip (16–512 px) and an export dialog that renders every size independently.

Same feel as Kantan Paint Tool and Kantan NineSlice: compact dark Fluent UI, tool rail, contextual top bar,
docks and the same Qt-free core architecture.
