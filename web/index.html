About Kantan Logo Maker

Kantan Logo Maker {{VERSION}}
A small, fast logo and icon maker.
Produced by Kingdom Pots using Claude Opus, GPT 6.1 Sol and Google Gemini 4

Frameworks & Open-Source Libraries:

  • Qt 6 (LGPL) — Cross-platform desktop user interface, windowing and graphics framework.
  • Clipper2 (BSL-1.0) — 2D polygon geometry library used for boolean shape operations (Union, Subtract, Intersect, Exclude) and path offsetting/outlines.
  • nanosvg (zlib) — Lightweight SVG parser used to import vector graphics and symbol presets.
  • Miniz (MIT) — Fast lossless data compression and ZIP archive library used to save and load .kantanlogo project files.
  • Fluent System Icons (MIT) — Microsoft's open-source icon set used for the toolbar and interface icons.
